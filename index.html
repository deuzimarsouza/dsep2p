PRIVACIDADE

Temporário, não invisível.

O tráfego usa HTTPS, mas o arquivo passa pelo servidor e fica temporariamente no Volume do Railway. O código funciona como a chave de acesso: envie somente para quem deve receber.

A aplicação não promete criptografia ponta a ponta nem substitui antivírus. Ao vencer o prazo — no máximo 24 horas — a API remove os arquivos automaticamente.
